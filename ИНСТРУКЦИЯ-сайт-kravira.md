# Сайт https://kravira.by/ – где что лежит и как править

Сайт работает на **1С-Битрикс**, готовое решение **Аспро: Медицинский центр 2** (шаблон `aspro-medc2`).

Корень сайта на сервере:

`/home/host1510/public_html`

Это же каталог открывается по симлинку `/home/host1510/www`. Домен `kravira.by` смотрит сюда.

Папка `/home/host1510/kravira.by` к сайту не относится: там только пустой `cgi-bin`, `test.php` и каталог `Vmeste`.

Отдельный статический лендинг `top.kravira.by` лежит в `/home/host1510/top.kravira.by` (обычный `index.html`, не Битрикс).

Доступ по SSH/SFTP уже записан в `.env` этой папки: `SSH_HOST`, `SSH_PORT`, `SSH_USER`, `SSH_PASSWORD`.

Админка сайта: https://kravira.by/bitrix/admin/

## Как устроен сайт

Битрикс делит сайт на три слоя.

1. **Файлы страниц** в `public_html`. У каждого раздела есть `index.php`. Он подключает шапку, подвал и компонент.
2. **База MySQL** `host1510_kravira`. В ней тексты услуг, врачей, цен, новостей, акций, отзывов, филиалов и заявки с форм.
3. **Шаблон** `public_html/bitrix/templates/aspro-medc2`. Он рисует шапку, меню, подвал и главную.

Рабочий шаблон – `aspro-medc2`. Копия `aspro-medc21` включается только если открыть страницу с параметром `?t=t`. Её для обычных правок не трогать.

На аккаунте два сайта в одной установке:

| Код | Адрес | Язык |
| --- | --- | --- |
| s1 | https://kravira.by/ | русский, основной |
| s2 | https://kravira.by/en/ | английская копия, свои инфоблоки |

Ниже всё про русский сайт s1, если не сказано иное.

### Как менять цену

Посетитель видит свойство **«Цена на карточке»**, код `PRICE`. Оно заполнено примерно у 621 позиции. В базе тип свойства числовой, но на сайте лежит текст в том виде, в каком его надо показать: `1702 руб.` или `от 1702 руб.`. Новый текст писать в том же виде, что у соседних цен этого раздела.

| Свойство | Код | Когда менять |
| --- | --- | --- |
| Цена на карточке | `PRICE` | всегда, это цена на сайте |
| Старая цена | `PRICEOLD` | только если поле уже заполнено (около 37 позиций) |
| Цена для фильтра | `FILTER_PRICE` | только если поле уже заполнено (единицы позиций), число без «руб.» |

Услуга в инфоблоке 20 сама цену не хранит. У неё есть привязка `LINK_PRICES` к элементам инфоблока 21. Менять нужно элемент прайса.

Админка: **Контент → Инфоблоки → Каталог (aspro_medc2_catalog) → Цены**. Найти позицию по названию, открыть, поле «Цена на карточке».

С сервера, через API Битрикса, после того как найден `ID` элемента:

```php
CIBlockElement::SetPropertyValuesEx($id, 21, ["PRICE" => "1702 руб."]);
CIBlock::clearIblockTagCache(21);
BXClearCache(true);
```

Потом открыть страницу цены на сайте и сверить цифру. Если висит старая версия, удалить содержимое `public_html/bitrix/html_pages/` и `public_html/bitrix/cache/`. Из консоли не вызывать `\Bitrix\Main\Data\StaticHtmlCache::deleteAll()`: в CLI этот вызов падает.

Прямой `UPDATE` в `b_iblock_element_property` для цены не использовать: свойство легко записать в неверном виде, а кеш не сбросится.

### Стиль карточки врача

Образец – страница Николая Николаевича Ланкевича: https://kravira.by/staff/lankevich-nikolay-nikolaevich/

Тексты врача лежат не в файле страницы, а в свойствах инфоблока 4. Шаблон сам печатает название свойства («Образование», «Повышение квалификации», «Участие в конференциях», «Перечень манипуляций») над значением.

| Что видит посетитель | Свойство | Код |
| --- | --- | --- |
| Большое описание | Перечень манипуляций | `ACTIVITY` |
| Образование | Образование | `EDUCATION` |
| Повышение квалификации | Повышение квалификации | `AWARDS` |
| Участие в конференциях | Участие в конференциях | `CONFERENCES` |
| Должность, категория, стаж | отдельные короткие поля | `POST`, `QUALIFICATION`, `WORK` |
| Пациенты: взрослые, дети или взрослые и дети | список | `ADULT_CHILD` |

Как собирать описание:

1. В `ACTIVITY` – одна карточка: серый фон `#f9f9f9`, белая плашка с тенью и скруглением 12px, имя цветом `#008080`, строка должности, стаж, вступление, разделители и списки. Выделенные блоки – фон `#e6f7f7`.
2. Образование, курсы и конференции – такие же белые карточки со списком, без второго заголовка внутри: название блока уже пишет шаблон.
2а. Рубрика «Пациенты» (значения «Взрослые», «Дети», «Взрослые и дети») – такая же карточка. Её рисует шаблон `news.detail/staff/template.php` для свойства `ADULT_CHILD`, если значение заполнено. Пустое свойство не показывать и не выдумывать. Тот же вид у фильтра списка врачей: «Пациент» и «Филиал», пункты с коротким тире. Стили фильтра – в `css/custom.css`, пометка `staff-rubric-cards`.
3. В свойство «Образование» один раз кладётся стиль страницы: подписи блоков бирюзовые, 20px, а маркер списка – короткое тире `–`, не символ U+2014.
4. В текстах только короткое тире (–). Дефис остаётся в сложных словах: врач-уролог, 2015–2016 для диапазона тоже короткое тире.
5. В карточку попадают только факты этого врача: должность, категория, стаж, курсы, операции и публикации, которые уже были в карточке. Чужие специализации не переносить.
6. Если перечня манипуляций не было, описание короткое: кто это, категория, стаж и то, что прямо написано в образовании. Пустой список операций не выдумывать.
7. После записи сбросить кеш Битрикса, иначе страница останется старой.

Этот вид уже стоит у урологов раздела «Урологи». Новому урологу повторять те же четыре свойства, а не верстать отдельный `index.php`.

## Что на диске есть, но сайтом kravira.by не является

Эти папки можно не трогать, если задача – править текущий сайт:

- `about`, `advertising`, `agreement`, `blogs`, `board`, `forum`, `photo`, `projects`, `themes`, `nationalnews`, `information`, `cart`, `cupons1`, `vote`, `events-calendar` – хвосты демо-шаблона и старых модулей
- `info/` – витрина элементов интерфейса Аспро (`/info/typograpy/`, кнопки, иконки)
- `0dev/` – черновик
- `en/` – английская версия, сайт s2
- `public_html/host1510_kravira.sql` – дамп базы от 29 декабря 2023, лежит в корне сайта
- `/home/host1510/public_html.tar` и `public_html_old.tar` – архивы от 14 декабря 2021, лежат выше корня сайта, в веб не отдаются
- `.htaccess1`, `.htaccess_`, `.htaccess_old_`, `.htaccess_back020602026` – старые копии правил Apache

Файл `public_html/.htaccess` рабочий, около 180 КБ, в основном редиректы. Его не переписывать целиком: сломаются старые адреса.

Свои обработчики PHP: `public_html/local/php_interface/init.php`. Там, в частности, для сайта s1 задан `FILIAL_IBLOCK_ID = 23` и вырезается часть служебного CSS Битрикса у гостей.

## Подключение к базе SQL

База одна, доступна только с самого сервера, хост `localhost`. С домашнего компьютера порт MySQL наружу не открыт.

Оба файла должны совпадать. Если поменять пароль только в одном, сайт перестанет открываться.

1. `public_html/bitrix/php_interface/dbconn.php`
   - `$DBHost`
   - `$DBLogin`
   - `$DBPassword`
   - `$DBName`
   - `$DBType = "mysql"`
2. `public_html/bitrix/.settings.php`
   - секция `connections → value → default`
   - класс `\Bitrix\Main\DB\MysqliConnection`
   - те же `host`, `login`, `password`, `database`

Текущие значения (пароль продублирован в локальном `.env`, переменная `DB_PASSWORD`):

| Параметр | Значение |
| --- | --- |
| Хост | `localhost` |
| База | `host1510_kravira` |
| Пользователь | `host1510_kravira` |
| Кодировка | UTF-8 (`BX_UTF` включён в `dbconn.php`) |

Пароль в инструкцию не копируется. Он в `.env` и в двух файлах выше.

### Зайти в базу с сервера

По SSH, из домашней папки аккаунта:

```bash
mysql --default-character-set=utf8mb4 -h localhost -u host1510_kravira host1510_kravira -p
```

Пароль спросить у `.env` / `dbconn.php`. Без `--default-character-set=utf8mb4` русские буквы в консоли будут знаками вопроса, в самой базе они в порядке.

### Зайти с локального компьютера

Сначала туннель, потом клиент (TablePlus, DBeaver, mysql). Пароль SSH – `SSH_PASSWORD` из `.env`.

```bash
ssh -L 3307:127.0.0.1:3306 -p 22 host1510@svh10.hoster.by
```

Дальше локально: хост `127.0.0.1`, порт `3307`, база и пользователь `host1510_kravira`.

Через панель Hoster тот же вход называется phpMyAdmin: база `host1510_kravira`.

### Какие таблицы за что отвечают

Префикс таблиц Битрикса – `b_`.

| Таблица | Содержимое |
| --- | --- |
| `b_iblock` | список инфоблоков (услуги, врачи, цены…) |
| `b_iblock_section` | разделы |
| `b_iblock_element` | элементы: название, код, активность, анонс, детальный текст |
| `b_iblock_element_property` | свойства: цена, должность, привязка к филиалу |
| `b_file` | файлы из `upload/`, связь с элементами |
| `b_lang` | сайты s1 и s2 |
| `b_site_template` | какой шаблон у сайта |
| `b_option` | настройки модулей |
| `b_user` | пользователи админки и кабинета |

Тексты элементов лежат в `b_iblock_element` (поля `NAME`, `CODE`, `PREVIEW_TEXT`, `DETAIL_TEXT`). Цена и прочие поля карточки – в `b_iblock_element_property`, не в самом элементе.

Прямые правки SQL имеет смысл делать только для поиска и выгрузок. Изменение текста через SQL не сбрасывает кеш и легко ломает свойства. Обычные правки – через админку.

Полезный просмотр услуг верхнего уровня:

```sql
SELECT ID, NAME, CODE, ACTIVE
FROM b_iblock_section
WHERE IBLOCK_ID = 20 AND IBLOCK_SECTION_ID IS NULL
ORDER BY SORT, NAME;
```

Инфоблоки русского сайта:

```sql
SELECT ID, CODE, NAME
FROM b_iblock
WHERE LID = 's1'
ORDER BY ID;
```

## Как править, коротко по типу задачи

| Задача | Куда идти |
| --- | --- |
| Услуга, описание, SEO услуги | Админка, инфоблок 20, либо режим правки на странице услуги |
| Цена | Админка, инфоблок 21 |
| Врач, фото, специальность | Админка, инфоблок 4 |
| Акция | Админка, инфоблок 47 |
| Новость | Админка, инфоблок 9. Точечный запрет URL – `news/index.php` |
| Отзыв | Админка, инфоблок 3 |
| Филиал, карта, режим работы филиала | Админка, инфоблок 23 |
| Телефон 403, почта, короткий адрес, копирайт | файлы в `public_html/include/` |
| Текст «Пациентам» | `patients/index.php` |
| Текст вступления к онлайн-записи | `zapis/index.php` и `include/zapis.php` |
| Страницы оплаты, лояльности, рассрочки, страховки, реквизитов, руководства | соответствующий `o-companii/.../index.php` |
| Пункт главного меню | `public_html/.top.menu.php` |
| Пункт меню «О клинике» | `o-companii/.left.menu.php` |
| Заголовок главной | `public_html/index.php` |
| Цвет, отступ, шрифт | `bitrix/templates/aspro-medc2/css/custom.css` |
| Состав блоков главной, тип шапки | Админка → Аспро → Настройки |
| Заявка с сайта | Админка, тип инфоблоков `aspro_medc2_form` |
| Логин, пароль, хост базы | сразу оба файла: `bitrix/php_interface/dbconn.php` и `bitrix/.settings.php` |

Режим правки на самом сайте: войти в админку, открыть страницу, включить «Режим правки». Так удобно менять включаемые области из `include/` и элементы, которые уже выведены на страницу.

После правки файла меню или шаблона очистить кеш в админке.
