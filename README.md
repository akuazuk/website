# kravira.by

Рабочие заметки по сайту медицинского центра «Кравира»: где лежат разделы, как менять цены, врачей и тексты.

Самого сайта в этом репозитории нет. Сайт – 1С-Битрикс на сервере, корень `/home/host1510/public_html`.

- Агенту начать с [AGENTS.md](AGENTS.md).
- Полная карта файлов, меню, инфоблоков и базы – [ИНСТРУКЦИЯ-сайт-kravira.md](ИНСТРУКЦИЯ-сайт-kravira.md). Там же: как зайти на сервер по SSH и как менять большой слайдер на главной.

Пароли в репозиторий не входят. Локально они лежат в `.env`, имена переменных – в `.env.example`. Новому агенту `.env` передавать отдельно от git. Если файла нет, пароль базы берётся на сервере из `dbconn.php` и `.settings.php`. Порядок – в инструкции, раздел «С чего начать новому агенту».

После правки сайта агент сохраняет прежнее значение, коммитит и пушит. Иначе откатить изменение нельзя: самого сайта в git нет. Порядок – в `AGENTS.md`, раздел «Коммиты и откат».
