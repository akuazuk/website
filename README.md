# kravira.by

Рабочие заметки по сайту медицинского центра «Кравира»: где лежат разделы, как менять цены, врачей и тексты.

Самого сайта в этом репозитории нет. Сайт – 1С-Битрикс на сервере, корень `/home/host1510/public_html`.

- Агенту начать с [AGENTS.md](AGENTS.md).
- Полная карта файлов, меню, инфоблоков и базы – [ИНСТРУКЦИЯ-сайт-kravira.md](ИНСТРУКЦИЯ-сайт-kravira.md).

Пароли в репозиторий не входят. Локально они лежат в `.env`, имена переменных – в `.env.example`.
